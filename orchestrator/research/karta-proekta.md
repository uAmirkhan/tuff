# Карта проекта TUFF

Разведка 25.09.2026, картограф. Состояние на коммит `681ca4b`.

## 1. Стек и структура

TypeScript (strict, ES2022, `noUncheckedIndexedAccess`), Vite 7, PixiJS 8 (единственная
рантайм-зависимость), Vitest 4, Biome 2, tsx. Физика — свой решатель, без сторонних движков.

**src/ — 9778 строк в 45 файлах:**

| `game/` | 8 + config (4) | ~1750 | Тело, враги, боссы, слияние, игровой цикл, прогресс |
| `level/` | 6 + urovni (19) | ~3500 | Формат, загрузчик, валидатор, Tiled, сами уровни |

Крупнейшие: `physics/mir.ts` 1154, `render/stsena.ts` 813, `game/igra.ts` 658, `main.ts` 625.

## 2. Как запустить

- `npm run dev` → `vite --host` (в локальной сети, для телефона)
- `npm run build`, `npm run preview`
- `npm test` / `npm run test:watch`
- `npm run lint` / `npm run format`
- **`npm run check`** — линт, типы, тесты, чистая комната. Команда «перед сдачей»
- `npm run cleanroom`, `npm run paket`, `npm run karty`

**Параметры адреса:** `?uroven=<id>` (прямой запуск), `?koop=1` (кооп, заглушка до меню),
`?komnata=1` (стенд), `?perf=1`, `?otladka=1`, `?chisto=1` (кадры без HUD),
`?ploshchadka=<имя>`.

## 3. Как проверить

35 файлов тестов, 3848 строк. Прохождения всех уровней ботом, физика, фазз случайным вводом,
обратимость Tiled, сохранение, боссы, кооп, сторожа устойчивости решателя.

68 скриптов в `scripts/`, вне `npm run check`, запускаются вручную:
захват кадров (`kadr*`, `konec-telefon`, `oblozhki.py`); замеры производительности
(`perf*`, `alloc`); тач (`tach-*`); кооп (`koop-*`, `kriostat-koop-zamer`, `proverka-koop-1`);
калибровка слияния (`sliyanie-kalibrovka`, `sliyanie-svoystva`); отладка механик
(`*-otladka`, `fazz-otladka`); геометрические замеры (`shchel*`, `most2*`, `stena`,
`vorota-*`, `hrupkiy-vdvoyom`, `pryzhok`, `udar*`); прочее (`dump*`, `sborka-proba`,
`zvuk-proverka`).

## 4. Фичи и состояние

Живы и покрыты проверками: решатель; тело и четыре способности; формат уровня (~30 типов
объектов, материалы базальт/лёд/хрупкий/металл); враги (Обрезок, Скачок, дрон Уборщик);
два босса (Тройной котёл, Криостат); кооп-движок и слияние; отрисовка и камера; звук
(полный процедурный синтез, без аудиофайлов); меню, карта мира, Журнал; сохранение через
подменяемое хранилище; локализация RU/EN; ввод с раздельными раскладками на двоих;
аналитика; обмен с Tiled.

**Единственная настоящая заглушка** — вход в кооп: сам режим рабочий, обвязки меню нет.
**Не подтверждено реальностью** — адаптеры площадок: код на три цели готов, живой публикации
и модерации не было.
