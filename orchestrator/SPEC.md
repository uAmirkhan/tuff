## Рамка релиза

**Пять ярусов** (решение Khan'а 25.09). 35 уровней против нынешних 8, то есть объём контента
— главная статья расходов проекта.

**Вне скоупа до особого решения:** экономика и валюты (Расчётчик, руда, скины), новый арт,
сетевой код, третий игрок, веб-площадки как источник дохода.

## Очередь: чем занимается цикл

Порядок выбран по видению — сперва довести кооп до живой пары, потом препятствия, потом
контент.

| № | Блок | Почему здесь |
|---|---|---|
| 1 | Кооп для живой пары: меню, лекарство от заморозки, полный прогон яруса 1 вдвоём | Проверяет главный риск дёшево, до производства 28 уровней |
| 2 | Клип-крючок и плейтест на парах | Отвечает на «кооп это каша или веселье» людьми, а не инженерией |
| 3 | Кооп-препятствия | Три провала подряд. Идут после проверки спроса, а не до |
| 4 | Ярусы 2-5 | Самое дорогое. Строится на подтверждённой механике |

### Не начато

| Фича | Критерий приёмки |
|---|---|
| **Лекарство от заморозки слитой пары** | Встречный ввод сейчас роняет скорость пары до 0%: партнёр останавливает её одной клавишей. Приёмка: при встречном вводе пара сохраняет не меньше трети хода |
| Деление экрана | Камера уже сообщает, что тела не влезли. Приёмка: на расхождении сверх порога экран делится и оба тела видны |
| Остывание по расстоянию | Числа за Khan'ом. Приёмка: порознь жар падает быстрее, вместе медленнее, слитым восстанавливается |
| Меню выбора кооператива | Сейчас только `?koop=1`. Приёмка: режим выбирается из меню и переживает перезапуск |
| Ярус 2 | Уровни по планам из вики, каждый с тестом прохождения и кооп-проверкой |
| Клип-крючок | Три секунды, на которых видно слияние. Приёмка: файл снят и просмотрен |
| Витрина Steam | Зона Khan: взнос и выплаты. В `inbox.md` |

## Ворота качества, действуют на каждую фичу

1. `npm run check` зелёный (формат, типы, тесты).
2. `npm run cleanroom` зелёный, `grep -rli` по имени референса пуст.
3. Уровень принимается ботом **и** живым прогоном в браузере, не только тестом.
4. Кооп-участок принимается бот-проверкой на пассажира, а не моим сценарием.
5. Замер делается **до** постройки уровня, с повторами.
